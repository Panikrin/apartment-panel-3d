# ЩР / 54

Публичная интерактивная концепция квартирного электрощита. Статический HTML/CSS/JS без внешних библиотек, аналитики, личной переписки и данных кабинетов.

Не рабочий электропроект и не инструкция монтажа. Состав и номиналы из исходных схем требуют обследования и расчётов. Геометрия, ширины, расположение портов и проводников условные.

R02: функциональные связи L/N/PE, отдельные N-группы, кросс-модуль 2×7, мастер-клавиша вне щита, условный вариант с ПММ. ПММ найдена в первичной схеме как линия №3; фактическое исполнение не подтверждено.

Проверка модели: `node check.mjs`. Просмотр: любой статический HTTP-сервер. Публикуется только эта директория, без исходных PDF и снимков корзины.
